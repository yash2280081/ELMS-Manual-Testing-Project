# ELMS – Manual Testing Project

## Project Overview

Employee Leave Management System (ELMS) is a web-based application used to manage employee-related activities and leave management.

This project was performed as part of software testing training to gain hands-on experience in manual testing.

## Role

**Manual Tester**

## Testing Activities

* Studied application functionality and identified test scenarios.
* Prepared test plan and test cases.
* Executed functional test cases.
* Verified login functionality using valid and invalid credentials.
* Tested different modules and user workflows.
* Identified and reported defects.
* Assigned Severity and Priority to defects.
* Maintained test documentation.

## Testing Types

* Functional Testing
* Smoke Testing
* Sanity Testing
* Regression Testing
* Retesting
* Black-Box Testing

## Test Case Design Techniques

* Equivalence Partitioning
* Boundary Value Analysis
* Decision Table Testing
* State Transition Testing
